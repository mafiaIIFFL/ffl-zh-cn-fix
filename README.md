# FFL 中文翻译及修复补丁

适用于《Mafia II: Definitive Edition / 黑手党2：最终版》Friends for Life 1.1 的简体中文兼容与翻译补丁。

## 功能

- 修复简体中文环境下 Friends for Life 无法正常进入的问题
- 修复 FFL 自定义菜单显示 `Undefined text id` 的问题
- 汉化 Friends for Life 自定义菜单文本
- 支持自动安装、状态检查、备份与卸载恢复
- 提供独立 Windows EXE，无需安装 Python

## 使用前提

请先安装：

- Mafia II: Definitive Edition
- Friends for Life 1.1

目前已在 **Epic Games 版 + 简体中文** 环境下完成实机测试。

## 使用方法

从 GitHub Releases 下载：

`FFL-ZH-CN-Patcher.exe`

双击运行后选择：

```text
[1] 安装 / 修复补丁
[2] 检查补丁状态
[3] 卸载补丁并恢复最近一次自动备份
[0] 退出
```

根据提示输入《Mafia II: Definitive Edition》的游戏根目录即可。

例如：

```text
E:\MafiaIIDE
```

该目录下应包含：

```text
pc
```

文件夹。

安装完成后，将游戏语言设置为 **简体中文**：

**附加内容 → 一生挚友**

即可正常游玩。

## 卸载

重新运行补丁程序，选择：

```text
[3] 卸载补丁并恢复最近一次自动备份
```

安装器会恢复安装前自动创建的备份。

## 说明

本项目不会分发《Mafia II: Definitive Edition》的原始游戏文件，也不会重新分发完整的 Friends for Life MOD。

补丁程序会基于玩家本人已经安装的游戏及 Friends for Life 1.1 文件进行修改。

建议在安装任何 MOD 前自行备份重要游戏文件。
